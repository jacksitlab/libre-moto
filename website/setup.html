Setup

Von null zu fahrbereit in vier Schritten. Alles ist Open Source — es gibt kein fertiges Image, du baust selbst.

Was du brauchst

  • Ein CrowPanel 2,1″ (ESP32-S3, 480×480 rund) oder einen kompatiblen Board-Bausatz
  • Ein Android-Smartphone (Android 10+) mit OsmAnd
  • Einen Rechner mit ESP-IDF (v5.3 oder v6.x) und Android Studio
  • Ein USB-C-Kabel für Flashen und Strom am Lenker

1 · Firmware flashen

Klone das Repository und baue die Firmware mit ESP-IDF. Das Board meldet sich danach als „LibreMoto“ per Bluetooth.

git clone https://github.com/jacksitlab/libre-moto
cd libre-moto/firmware/esp-idf
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor

2 · App installieren

Die Android-App baut du aus dem selben Repository (Android Studio oder Gradle). Sie verbindet sich automatisch mit dem Display.

cd libre-moto/app
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/

3 · OsmAnd einrichten

Für die Live-Karte braucht die App Route und Straßendaten aus OsmAnd. Dafür gibt es einen gepatchten OsmAnd-Build (AIDL-Erweiterungen) — das Build-Skript liegt im Repository.

cd libre-moto/scripts
./build-osmand-fork.sh

4 · Karten laden

In der App lädst du Regionen aus dem Geofabrik-Index (z. B. Brandenburg). Die Region wird auf dem Gerät in das .lmm-Format umgewandelt — fertig.

Kein Befehl — Regionen werden direkt in der App ausgewählt und heruntergeladen.
